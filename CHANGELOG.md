# Changelog

## 0.1.0

First release.

- `assemble(target, options)` builds any element with a crew of multiplayer cursors.
- Zero dependencies: a built-in `requestAnimationFrame` timeline replaces GSAP.
- React entry (`cursorcrew/react`) with `<Assemble>` and `useAssemble`.
- CDN bundle exposing `window.CursorCrew`.
- Respects `prefers-reduced-motion` by default.
