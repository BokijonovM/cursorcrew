Your page, built live by a crew of agents.

What the agents do

box

Draw every surface

Anything with a fill, border or shadow is dragged out with a crosshair and a live W × H badge, then fades in.

text

Type every line

Headings and paragraphs get a text frame and a caret. Short text types by letter, long text by word.

media

Place images and charts

Images, SVG, video and canvas get a striped placeholder, then sweep in from the top.

order

Respect the tree

Children wait for their parent box. Free agents pick the nearest ready task, so work spreads across the page.

Two lines to use it

import { assemble } from 'cursorcrew';

const crew = assemble('#app', {
  agents: 5,
  duration: 8,
  trigger: 'viewport',
});

crew.timeline; // play, pause, progress, timeScale
import { Assemble } from 'cursorcrew/react';

export default function Hero() {
  return (
    <Assemble options={{ agents: 4 }}>
      <h1>Hello world</h1>
    </Assemble>
  );
}
