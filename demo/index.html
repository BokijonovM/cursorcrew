How it works

What the agents do

Every element on the page becomes a task. A crew of cursors picks them up in order and rebuilds the page in front of you.

Draw every surface

Anything with a fill, border or shadow is dragged out with a crosshair and a live W × H badge.

Type every line

Headings and paragraphs get a text frame and a caret. Short text types by letter, long text by word.

Place media

Images, SVG, video and canvas get a striped placeholder, then sweep in from the top.

Respect the tree

Children wait for their parent box. Free agents grab the nearest ready task, so work spreads out.

Quick start

Two lines to use it

Works with plain JavaScript or React. Ships ESM, CJS and a script-tag build.

main.js 
import { assemble } from '@bokijonovm/cursorcrew';

const crew = assemble('#app', {
  agents: 5,
  duration: 8,
  trigger: 'viewport',
});

crew.timeline; // play, pause, progress, timeScale
Hero.tsx 
import { Assemble } from '@bokijonovm/cursorcrew/react';

export default function Hero() {
  return (
    <Assemble options={{ agents: 4 }}>
      <h1>Hello world</h1>
    </Assemble>
  );
}
